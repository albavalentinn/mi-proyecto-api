# 🎮 API REST: Videojuegos y Desarrolladores

Esta es una API RESTful desarrollada con **FastAPI** y **Python**, acompañada de un frontend ligero (HTML, CSS y JavaScript Vanilla). Permite gestionar una base de datos relacional (1:N) de Desarrolladores y sus respectivos Videojuegos.

## 🛠 Tecnologías Utilizadas
* **Backend:** Python 3, FastAPI, Uvicorn.
* **Base de Datos:** SQLite, SQLAlchemy (ORM), Pydantic (Validación de esquemas).
* **Frontend:** HTML5, CSS3, JavaScript (Vanilla), Axios (Peticiones asíncronas).
* **Arquitectura:** Modular (Controladores, Modelos, Esquemas y Rutas separadas).
